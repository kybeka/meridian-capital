# Matching presentation draft

This fills the team's existing Beamer template with 17 slides that match the completed report: Round 1 results, attribution, funding, risk, the six stock cases, cash-flow checks, alphas and credibility. The logo, palette, author order and 16:9 layout are retained; the font is DM Sans.

The [shared presentation](https://www.overleaf.com/project/6ae9e2672f6ea8c4f0fddc87) is view-only, so these changes have **not** been applied there. Keep that project as the shared version. Once editing access is granted, upload the included font files and replace its `main.tex` after checking for intervening team edits. Select **XeLaTeX**, then compile twice.

To compile this folder locally, run `xelatex main.tex` twice. Its PDF is a review draft, not a record of a course submission. Sources and assumptions are detailed in the report and notebooks.
