# Checkpoint 2 presentation

[View the final PDF](../AMC2_Presentation.pdf) or open the [shared Overleaf project](https://www.overleaf.com/project/6ae9e2672f6ea8c4f0fddc87). There are 15 main slides and 7 backup slides. The [rehearsal notes](rehearsal_notes.md) include a suggested five-person speaking order and answers to likely questions.

The presentation follows the submitted report and recorded holdings. Its wording was revised on 9 November 2026; the figures, formulas, weights and quantities are unchanged. It uses the team's 16:9 layout, DM Sans, colours, logo and author order.

To compile, run `xelatex main.tex` twice from this directory. All required fonts and the logo are included. Speaker notes are also stored in the Beamer source. The [source archive](../AMC2_Presentation_Source.zip) contains the same LaTeX files.
