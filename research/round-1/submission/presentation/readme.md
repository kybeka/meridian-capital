# Round 1 presentation

These are the complete files downloaded from the [shared Overleaf project](https://www.overleaf.com/project/6acf74587cbaa56d0ba71183) on 12 November 2026. The [PDF](../presentation.pdf) has 16 pages and includes the team's latest wording. Earlier PDF versions remain in Git history.

`main.tex`, the three chart PDFs, the logo and `fonts/` are included. Upload this directory or [Presentation_Source.zip](../Presentation_Source.zip) to Overleaf and select XeLaTeX. To compile locally, run `latexmk -xelatex main.tex` from this directory, or use the repository's [document build helper](../../../documents.md).
