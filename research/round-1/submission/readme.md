## Editing the report later

Open `latex/main.tex` in Overleaf with the `fonts/` and `figures/` folders alongside it. Select XeLaTeX as the compiler. Alternatively, from the `latex` directory, run `latexmk -xelatex main.tex` with a suitable TeX installation.

The submitted PDFs are archived unchanged. The LaTeX folder preserves the saved editable report project; generated build files are omitted. The presentation is archived as PDF; its editable slide source was not included in the supplied files.
