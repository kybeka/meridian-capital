# Round 1 analysis

Open **round1_analysis.ipynb** in Jupyter and read from top to bottom. Restart the kernel and Run All to reproduce the submitted allocation, benchmarks, backtest and whole-share positions. The saved notebook includes executed tables and figures.

**supplementary_studies.ipynb** is separately runnable evidence: 108 constraint specifications, Yahoo/Bloomberg comparisons, two historical-fit checks, cost sensitivity and Sharpe uncertainty. It does not change the submitted allocation.

- Data/: original Bloomberg workbook, original FRED yields, earlier Yahoo prices, and chosen closing prices/share quantities. All inputs are directly in this folder.
- Results/: current tables and the backtest chart, generated by the main notebook.
- Studies/: supplementary tables, chart and the retained research-variations ledger.

Use an existing Python environment with the packages in requirements.txt. Open Jupyter from this folder so relative Data/ paths resolve. There are no project scripts to run behind the notebook and no JSON metadata sidecars. Historical source dates, estimation windows and limitations are explained where they affect the calculations.

The main historical comparison is retrospective, not an untouched holdout. Capital/risk limits are policy choices. Raw Bloomberg data is included with the user's authorization. Earlier code and pack versions remain recoverable through Git history; they are not separate current implementations.
