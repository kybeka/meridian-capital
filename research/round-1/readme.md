# Round 1 portfolio analysis

Open `round1_analysis.ipynb` for the allocation method, formulas, input charts, portfolio comparisons and share quantities. Select Restart Kernel and Run All to reproduce it. The saved notebook includes the results.

`supplementary_studies.ipynb` contains constraint sensitivity, data-source comparisons, earlier fitting windows, cost sensitivity, Sharpe uncertainty and the optional accounting reconciliation.

- `data/`: Bloomberg prices, the original export, FRED yields, earlier Yahoo prices and position quantities.
- `results/`: main calculation tables and charts. Charts are saved as PNG and PDF for use in the report.
- `studies/`: supporting calculation tables and charts.

Open Jupyter from this folder so the relative paths resolve. Package requirements are in `requirements.txt`.
